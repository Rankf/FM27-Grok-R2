# 安装器源文件

R2.4 安装器必须配合完整包 bundles、originals、skins 使用；单独克隆仓库不能安装。

Build 不同只警告，相关资源及样式必须匹配。legacyGrokV2 分支仍要求对应 Steam 清单确认实际 Build 为本包制作基准 26577676。未知资源不放行。

恢复要求实际 Build 等于制作基准，或 FM27_Grok_InstallState.json 记录本安装器在同一 Build 见过全部匹配的干净原版资源。Build 再次变化使记录失效；没有证据时使用 Steam 验证恢复。

菜单 5 只启用真实 CA，菜单 6 启用 CA+PA，菜单 7 恢复 CA/PA 原始显示指令。R2.4 扫描 PE 可执行区，只有唯一一对 CA/PA 判断汇合到受支持的隐藏值分支时才操作，不再依赖完整 DLL 哈希。写入先在副本中完成并重新扫描验证，再替换原文件；失败会回滚。该功能不依赖游戏内修改器，不改变存档或球员数值，也不覆盖 DLL 的其他修改。

Diagnostics 报告包含警告、资源判定、canRestore 及 DLL 状态。皮肤资源写入前备份，写入失败尝试回滚。
