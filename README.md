# FM27 Grok R2.1 测试适配包

基于 FM27_grok v2.0 的非官方适配，仅面向 Windows Steam **Build 26385295**。

**目前是测试版，尚未完成游戏内全面验证。** 不包含隐藏属性补丁，不修改 `game_plugin.dll` 或游戏存档。原皮肤中的隐藏按钮或列可能仍然可见。

**“正式版适配”仅指上述具体 Build，并不代表支持所有正式版更新或所有已有皮肤环境。** 安装器按资源文件校验值判断是否允许操作；窗口顶部的 Build 号是适配目标，不是检测出的用户游戏版本。

## 下载与安装

R2.1 以安装器更新补丁发布，复用 R2 的全部界面资源。

- 首次使用：先下载 [R2 完整包](https://github.com/Rankf/FM27-Grok-R2/releases/download/r2-test/FM27_Grok_26385295_R2_Test_NoHidden.zip)并解压，再应用下面的小补丁。不要下载 GitHub 自动生成的 Source code ZIP。
- 已有 R2 完整目录：在 [R2.1 更新页面](https://github.com/Rankf/FM27-Grok-R2/releases/tag/r2.1-test) 下载 `FM27_Grok_R21_Installer_Update.zip`，将其中的 `install.ps1` 和 `manifest.json` 覆盖到原 R2 目录，与 `Install.bat` 同级。

**小补丁不能独立使用，必须保留完整 R2 的 bundles、originals 和 skins。** 应用后标题会显示 R2.1。

1. 完整解压安装包，退出游戏。
2. 双击 `Install.bat`。
3. 选择 **1 固定侧边栏**或 **2 浮动侧边栏**，再选择游戏分辨率。
4. 如自动定位失败，输入包含 `fm_Data` 的游戏目录，以及包含存档、`skins` 的用户目录。
5. 重启游戏，在设置中选择 `FM27_grok`。

菜单 **3** 卸载并恢复本包匹配的基础资源；菜单 **4** 只检查兼容性。版本不匹配会拒绝操作，不提供强制覆盖。

## 出现“版本不兼容或文件被其他补丁修改”怎么办？

这表示提示中的文件没有匹配安装器支持的校验值，**不代表换电脑、换盘符就不能用，也不能据此断定游戏损坏**。安装位置可以不同；自动定位不到时手动输入实际目录。

| 游戏文件状态 | 当前支持范围 |
| --- | --- |
| Steam Build 26385295 对应的干净基础资源 | 纳入校验列表，应能通过资源校验；通过不等于所有游戏界面都已实测 |
| 本项目已识别的首版／R2 测试包文件 | 纳入升级或重复安装校验 |
| 本项目已核对的旧 Grok v2.0 文件 | R2.1 新增识别；必须从该安装对应的 Steam 清单确认实际 Build 为26385295后才允许升级 |
| 未收录的旧皮肤或其他比赛界面补丁 | 仍可能被拒绝，不能保证直接覆盖升级 |
| 其他 Steam Build、Xbox／Game Pass 或其他平台 | 未验证，不应按通用兼容包使用 |
| 文件缺失、损坏或其他未知内容 | 停止操作，需要进一步核对 |

选择 **4：只检查兼容性** 不会修改游戏文件。仅凭报错截图，无法区分游戏更新、旧皮肤残留、其他补丁或文件缺失。

处理顺序：

1. 先核对实际 Steam Build ID，并记录之前安装过哪些皮肤或界面补丁。
2. 如果实际 Build 不同，请等待相应适配，不要绕过校验或手动覆盖本包资源。
3. 如果 Build 相同且有旧补丁，可退出游戏，通过 Steam“验证游戏文件完整性”恢复当前平台提供的原版文件，再选 **4** 检查。验证可能撤销其他游戏文件补丁；若 Steam 已有新更新，恢复后的版本也可能超出本包支持范围。
4. 仍失败时，请按下方反馈要求提交实际 Build ID 和报错文件 SHA-256。不要反复安装或直接修改安装器白名单。

R2.1 会一次列出全部资源状态，并在安装包的 `Diagnostics` 目录生成 JSON 诊断报告。报告包含目标与实际 Build、文件名、大小、SHA-256及判定，不写入游戏文件；只检查时无需填写用户文档目录。无法确认实际 Build 时，已知旧 Grok 文件也不会被直接放行。

完整包的 `originals` 已有目标版本的7个原版资源，包括 `ui-datacollections_assets_all.bundle`。不建议脱离版本信息单独交换原版文件或跨版本手动覆盖。文件创建／修改时间不能单独证明“Steam验证后又被某个补丁覆盖”。

基础文件已补做 Steam 缓存下载清单核对，7 个资源全部匹配，包含已收到反馈的比赛界面资源。核对范围与记录见 [基础资源校验说明](docs/BASELINE_CHECK.md)。这项检查不能替代对反馈者实际文件的核对。

## R2.1 安装器修正

确认 R2 未识别原 Grok v2.0 的部分文件状态，例如 datacollections 的 `cddf4059…`，可能误拦截目标正式版上的旧皮肤残留。R2.1 收录了实际取得的 v2.0 包内校验值，并增加实际 Build 检查；没有放行任意未知文件。

同时改进 Steam 多库发现，区分文件缺失与未知修改，输出实际校验值和诊断报告。界面资源与 R2 逐字节一致，不包含新的 UI 功能或隐藏属性补丁。

安装器源文件见 [installer](installer)，模拟测试结果见 [r21-installer-tests.json](docs/r21-installer-tests.json)。测试覆盖旧 v2.0 两种侧栏升级、重复安装、恢复、未知文件、缺失文件、错误 Build、无法确认 Build 和写入失败回滚。仍未完成游戏内全面验证。

## R2 界面修正

原皮肤将 `XGTableTile_8x4` 资源改造成浮动侧栏。首个测试适配包误保留了原版表格，导致侧栏展开后出现 XG TABLE。R2 恢复了完整侧栏，并迁移正式版新增字段。

已检查侧栏 24 个菜单项、208 个托管引用、展开按钮的目标资源与内联样式引用。

## 验证与限制

- 资源封装与读回校验通过。
- 在模拟目录中测试了安装、重复安装、侧栏切换、卸载、未知版本拒绝和写入失败后的回滚。
- 安装器保持游戏 DLL 原样。
- 2026-11-11：7 个基础资源与目标 Build 对应的本机 Steam 缓存下载清单逐项核对通过；这不是其他平台或后续版本的兼容认证。
- **上述检查不等于游戏内实测。** 需要检查侧栏、球员及职员页、俱乐部历史、战术、比赛和存档载入。
- 战术角色详细／简化说明及比赛 `OverviewHeader` 保留正式版对象，与原皮肤可能存在差异。
- 未移植旧安装器的韩文字体加粗、主菜单背景和自定义背景开关。

每次操作前会在游戏目录的 `FM27_Grok_26385295_Backups` 中保存相关文件。游戏更新后请等待对应适配；如果已更新，不要用旧包恢复旧资源，可以通过 Steam 验证游戏文件完整性。

## 反馈

请在 [Issues](https://github.com/Rankf/FM27-Grok-R2/issues) 中提供：

- 游戏平台及**实际 Steam Build ID**，不是安装器标题显示的数字。
- 安装包版本、选择的菜单项，以及完整报错文件名和文字。
- 之前安装过的皮肤／比赛界面补丁，是否已验证游戏完整性。
- 校验失败时，提供对应文件的 **SHA-256**。
- R2.1 用户优先附上 `Diagnostics/compatibility_*.json` 报告，其中已包含上述版本和资源信息。
- 如果安装成功但显示异常，提供侧栏类型、游戏分辨率、Windows 缩放比例、复现步骤及截图。

**查 Build ID：** 在该游戏所属 Steam 库的 `steamapps/appmanifest_4530370.acf` 中，用记事本查找 `"buildid"`，只需提供这一行。

**查报错文件 SHA-256：** 打开 PowerShell，将下面路径改成自己的实际游戏目录后执行。这条命令只读取文件，不修改游戏。

```powershell
$game = 'D:\SteamLibrary\steamapps\common\Football Manager 27'
Get-FileHash -LiteralPath "$game\fm_Data\StreamingAssets\aa\StandaloneWindows64\ui-visualtreeassets_assets_matchvisualtreeassetpreload.bundle" -Algorithm SHA256 | Format-List Hash
```

如果报错的是其他文件，请相应替换文件名。不要提交完整存档或账号凭据。
