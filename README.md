# FM27 Grok R2.6.2

适配 Windows Steam FM 27.1.1，基准 Build 26797085。R2.6.2 恢复 Grok 球员页的真实 CA 运行时显示，并将其与皮肤栏位的选择一起处理。

[下载完整安装包](https://github.com/Rankf/FM27-Grok-R2/releases/download/r2.6.2-test/FM27_Grok_26797085_R262_Full_CA_Optional.zip) · [更新说明](RELEASE_NOTES_R262.md) · [SHA-256](SHA256SUMS_R262_FULL.txt)

## 使用

退出 FM，完整解压 ZIP，双击 Install.bat。首次使用先选菜单 1 或 2 并选择分辨率，再选 5 或 6，重启游戏并选择 FM27_grok。R2.6.1 已安装用户可直接使用菜单 5。

| 菜单 | 功能 |
| --- | --- |
| 1 | 安装固定侧栏 |
| 2 | 安装浮动侧栏 |
| 3 | 卸载并恢复匹配的基础资源和运行时显示判断 |
| 4 | 检查资源、报告运行时状态 |
| 5 | 在 Grok 显示真实 CA，隐藏 PA |
| 6 | 显示真实 CA 和 PA |
| 7 | 隐藏两项，并恢复原始运行时显示判断 |

菜单 5、6 会定位并修改本机 game_plugin.dll 的 CA／PA 显示结构。操作前保存 DLL 和皮肤样式备份，校验副本后替换。样式替换失败会回滚 DLL。重复选择同一模式可安全执行。安装器对同一游戏目录的并发操作加锁。

运行时显示备份位于实际 FM 用户目录下的 FM27_Grok_26797085_Backups；侧栏安装及卸载备份位于游戏目录下同名文件夹。安装器自动检测 Steam 目录和文档目录，也支持手动指定。

## 验证情况

2026-11-25，本机用户已在实际存档中确认仅 CA 显示正常。CA+PA 模式已通过文件级切换及还原检查，游戏内显示有待确认。固定／浮动侧栏和战术板头像采用已验证的 R2.6.1 界面资源。

完整 ZIP 经解压测试，覆盖模式切换、重复安装、侧栏切换保留选择、文件被占用时回滚和卸载还原。游戏更新后应重新运行菜单 4；无法识别的资源或运行时结构会阻止对应操作。
