# FM27 Grok R2.6.1

适用于 Windows Steam 版《足球经理 27》，适配基准为 27.1.1（Build 26797085）。本版包含固定侧栏、浮动侧栏、战术板头像界面、CA／PA 显示选项，以及与这次游戏更新匹配的界面资源和还原文件。

**[下载 R2.6.1 完整安装包](https://github.com/Rankf/FM27-Grok-R2/releases/download/r2.6.1-test/FM27_Grok_26797085_R261_UI_CA.zip)** · [更新记录](RELEASE_NOTES_R261.md) · [SHA-256 校验值](SHA256SUMS_R261_FULL.txt)

## 安装与升级

退出 FM27，将完整 ZIP 解压到同一文件夹，双击 `Install.bat`。首次使用本版或从 R2.6 升级，先选 **1** 或 **2** 并选择分辨率。进入游戏设置后选择 `FM27_grok`。如果 Steam 游戏更新前安装过 R2.5.3，可先用菜单 **4** 核对现有资源。

| 菜单 | 用途 |
| --- | --- |
| 1 | 安装固定侧栏 |
| 2 | 安装浮动侧栏 |
| 3 | 卸载皮肤并恢复与当前安装匹配的基础资源 |
| 4 | 只检查兼容性，在安装包的 Diagnostics 文件夹生成报告 |
| 5 | 球员属性页及角色选择页只显示 CA，隐藏 PA |
| 6 | 在上述两页显示 CA 和 PA |
| 7 | 隐藏上述两项 |

首次安装默认隐藏两项。切换显示模式前退出游戏，选好后重启。切换侧栏会保留已选模式。CA 和 PA 取自游戏提供给这两个界面的数值，字段为空时，选择显示也不会产生数值。

安装器自动查找 Steam 游戏目录和用户文档目录。手动指定路径时，游戏目录应包含 `fm_Data`，用户目录应是实际存放 `games` 或 `skins` 的文件夹。更新后版本号不同会提示并逐项检查资源。发现未知资源时会停止写入，具体文件见诊断报告。
